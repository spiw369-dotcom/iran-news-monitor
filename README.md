# Iran News Monitor

هر روز صبح ۱۵ منبع معتبر رو چک می‌کنه و هر خبر/یادداشت/مقاله/تحلیل مرتبط با
ایران رو با لینک به یک بات تلگرام می‌فرسته.

## راه‌اندازی (فقط یک‌بار)

### ۱. ساخت بات تلگرام
1. تو تلگرام برو سراغ `@BotFather`.
2. دستور `/newbot` رو بزن، یه اسم و یوزرنیم بده.
3. یه توکن بهت می‌ده شبیه این: `123456789:ABCdefGhIJKlmNoPQRstuVWXyz`. نگهش دار.

### ۲. گرفتن Chat ID
1. با باتی که ساختی یه پیام بفرست (مثلاً بنویس "سلام").
2. تو مرورگر برو به این آدرس (به‌جای `<TOKEN>` توکن خودت رو بذار):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. تو جواب JSON دنبال `"chat":{"id": ...}` بگرد. اون عدد Chat ID توئه.
   (اگه می‌خوای پیام‌ها بره تو یه گروه، بات رو به گروه اضافه کن و همون‌جا پیام بده.)

### ۳. ساخت ریپازیتوری در گیت‌هاب
1. یه ریپوی جدید (می‌تونه Private باشه) بساز، مثلاً `iran-news-monitor`.
2. سه فایلی که ساختم رو توش آپلود کن (با همین ساختار پوشه‌ها):
   - `iran_news_monitor.py`
   - `requirements.txt`
   - `.github/workflows/daily-iran-news.yml`

### ۴. اضافه‌کردن Secretها
تو ریپو برو به: `Settings → Secrets and variables → Actions → New repository secret`
دو تا secret بساز:
- `TELEGRAM_BOT_TOKEN` → همون توکن مرحله‌ی ۱
- `TELEGRAM_CHAT_ID` → همون عدد مرحله‌ی ۲

### ۵. تست
از تب `Actions` ریپو، وارد workflow به اسم **Daily Iran News Monitor** بشو و
دکمه‌ی `Run workflow` رو بزن (اجرای دستی). اگه همه‌چی درست باشه، چند ثانیه بعد
پیام تو تلگرامت میاد. بعد از این، هر روز خودکار ساعت تنظیم‌شده اجرا می‌شه.

## نکات مهم / محدودیت‌ها

- **بازه‌ی زمانی**: فقط خبرهایی که در ۳۰ ساعت اخیر منتشر شدن در نظر گرفته
  می‌شن، تا خبر تکراری هر روز نیاد.
- **دقت فیلتر کلمه‌کلیدی**: بعضی فیدها فقط عنوان و خلاصه دارن، نه متن کامل.
  اگه کلمه‌ی "Iran" فقط در بدنه‌ی مقاله باشه (نه عنوان/خلاصه)، ممکنه از
  قلم بیفته. اگه بعداً خواستی دقیق‌تر بشه، می‌تونیم یه مرحله اضافه کنیم که
  صفحه‌ی کامل مقاله‌های مشکوک رو هم بخونه.
- **پایداری آدرس‌های RSS**: آدرس فیدها گاهی توسط خود سایت‌ها تغییر می‌کنه.
  اگه دیدی یه منبع دیگه چیزی نمی‌فرسته، بگو تا آدرسش رو آپدیت کنم.
- **زمان اجرا**: کرون گیت‌هاب گاهی چند دقیقه تأخیر داره (عادیه، مشکل خاصی نیست).
- می‌تونی لیست کلیدواژه‌ها و منابع رو هر وقت خواستی توی
  `iran_news_monitor.py` (متغیرهای `FEEDS` و `KEYWORDS`) عوض کنی.

## گزینه‌های بعدی (اگه خواستی توسعه بدیم)
- اضافه‌کردن فیلتر برای زبان فارسی (اگه بخوای رسانه‌های فارسی‌زبان هم اضافه بشن).
- خلاصه‌سازی خودکار هر خبر با AI به‌جای فقط لینک.
- دسته‌بندی خبرها (سیاسی / اقتصادی / نظامی / هسته‌ای).
- ذخیره‌ی سابقه‌ی لینک‌های ارسال‌شده برای دقت بیشتر در حذف تکراری.
